## Selected projects

### [Slink](https://github.com/jaesungkr/slink)
**Windows utility · Released**

선택한 창을 화면과 작업 표시줄에서 숨겼다가 다시 복원하는 Windows 도구.  
Python과 Win32 API로 창을 제어하고, HTML/CSS UI·시스템 트레이·자동 업데이트를 연결했다.

[Download](https://github.com/jaesungkr/slink/releases/latest) · [How it works](https://github.com/jaesungkr/slink#how-it-works) · [Source](https://github.com/jaesungkr/slink)
